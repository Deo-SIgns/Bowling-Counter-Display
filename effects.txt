#
#  HOW TO TURN ONE OFF
#   Put a # at the start of its line. Remove the # to turn it back on.
#
#  HOW OFTEN EACH ONE PLAYS
#   The number after = is how likely it is to be picked, compared with
#   the others. 12 comes up about twice as often as 6. Leave the number
#   off (just the name) to use the normal amount.
#
#  Changes show up on the wall in about 10 minutes.
#  Effects marked (heavy) work the computer hardest. If the videos
#  stutter during surprises, turn those off first.
# ============================================================
